## 🛰️ Visão Geral do Sistema
> **Status:** `OPERACIONAL` 🟢  
> **Objetivo:** Centralizar o histórico de desenvolvimento, laboratórios de código e arquitetura de software desenvolvidos durante a graduação de **Sistemas de Informação** no Instituto Federal de Mato Grosso.

Este repositório funciona como o núcleo principal (`main-frame`) de toda a produção técnica de software do curso, documentando a evolução acadêmica e habilidades em engenharia de software em um único ambiente unificado.

* **Redes de Computadores:** Configuração, manipulação de servidores de rede e gerenciamento via terminais remotos (`SSH`, `CLI`).
* **Eletrônica Digital:** Análise teórica e práticas de circuitos lógicos diretamente em laboratório físico.
